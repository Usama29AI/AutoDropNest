
# 🚀 AutoDropNest

**AutoDropNest** is a modern, mobile-first, zero-cost dropshipping research and management SaaS platform. Designed specifically for solo entrepreneurs and beginners, it provides core tools like winning product discovery, profit calculators, and automated scaling funnels without expensive upfront investments.

---

## 🌟 Key Features

* **Winning Products Directory:** Hand-picked and trend-analyzed items with supplier costs, target sell prices, and net profit estimations.
* **Smart Profit Calculator:** Real-time calculation tool factoring in supplier cost, selling price, and advertising expenses to compute net margins instantly.
* **Tiered Growth Funnel:** Built-in model supporting a 1-month free trial, introductory growth rates, and full pro plans.
* **Mobile-First Responsive UI:** Fully optimized layout for mobile devices, letting you manage your store on the go.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid, Custom CSS Variables), JavaScript (ES6)
* **Hosting & Deployment:** GitHub & Vercel (100% Free Tier)

---

## 📊 Business & Pricing Funnel

1. **Month 1:** 100% Free Trial (Secure verification enabled)
2. **Months 2 & 3:** Growth Plan ($5/month introductory tier)
3. **Month 4 Onwards:** Pro SaaS Plan ($25/month full scale)
4. **Annual VIP Option:** Discounted annual subscription for long-term users.
